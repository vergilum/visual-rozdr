# Сценарий оператора

## Запуск

1. Дважды кликнуть `start_visual_pozdr.bat`.
2. Дождаться успешной проверки запуска.
3. Не закрывать окно `.bat` до конца мероприятия.
4. Использовать открывшуюся вкладку `/admin` как панель оператора.

## Подготовка мероприятия

1. Создать новое мероприятие или выбрать сохранённое.
2. Заполнить название компании и текст экрана.
3. Настроить громкость, цвета и фон при необходимости.
4. Открыть `/screen` на втором мониторе или проекторе.
5. Нажать «Запустить показ» на `/screen`, чтобы браузер разрешил звук.
6. Открыть приём сообщений.
7. Показать гостям QR-код.

## Работа с поздравлениями

1. Следить за блоком «На проверке».
2. Открывать предпросмотр при необходимости.
3. Исправлять имя гостя при необходимости.
4. Нажимать «Одобрить» для подходящих роликов.
5. Нажимать «Отклонить» для неподходящих роликов.
6. Использовать «Одобрить все ожидающие» только после проверки содержимого.

## Управление показом

1. Нажать «Запустить» в блоке «Сейчас на экране».
2. Использовать «Пауза», если нужно временно остановить текущий ролик.
3. Использовать «Продолжить», чтобы продолжить с той же позиции.
4. Использовать «Пропустить», если ролик не нужно досматривать.
5. Использовать «Остановить показ», если нужно остановить общий показ и вернуть текущий ролик в очередь.
6. Использовать «Показать повторно» из истории или принятых кружочков, если ролик нужно повторить.
7. В блоке «Стена» нажать «Запустить» у нужного ролика, если экран свободен. Если кнопка заблокирована, сначала остановить или пропустить текущий ролик.

## Завершение

1. Закрыть приём сообщений.
2. Дождаться завершения очереди или остановить показ.
3. Закрыть `/screen`.
4. В окне `.bat` нажать `Ctrl+C` и подтвердить остановку.
