# Проверка FFmpeg Runtime В Electron

## Цель

Подтвердить, что Windows-инсталлятор обрабатывает Telegram `video_note` без установленного в системе FFmpeg и без записи FFmpeg в `PATH`.

## Подготовка

1. Использовать чистую Windows VM или ноутбук без `ffmpeg.exe` и `ffprobe.exe` в `PATH`.
2. Установить `artifacts/electron/Visual Pozdr Setup 0.1.0.exe`.
3. Настроить Telegram-токен и username в `.env` пользовательской папки приложения.
4. Запустить Visual Pozdr и создать активное мероприятие с открытым приёмом.

## Проверка

1. Открыть `/admin`, найти блок «Диагностика».
2. Убедиться, что `ffmpeg` и `ffprobe` имеют статус `available`.
3. Убедиться, что их пути указывают на `resources/runtime/ffmpeg/`, а версии заполнены.
4. Отправить настоящую Telegram `video_note`, выбрать стол и дождаться обработки.
5. Проверить последовательность `received` → `downloading` → `processing` → `ready`.
6. Убедиться, что созданы prepared MP4 и JPEG-превью, а ролик доступен для предпросмотра в `/admin`.
7. Открыть ролик на `/screen` и убедиться, что видео воспроизводится.

## Отрицательная Проверка

1. Во временной копии unpacked-приложения переименовать `resources/runtime/ffmpeg/ffmpeg.exe`.
2. Запустить приложение и открыть `/admin`.
3. Убедиться, что диагностика показывает `ffmpeg: missing`, а worker имеет `tools_missing` с понятным текстом причины.
4. Убедиться, что новый ролик не переходит в `failed` только из-за отсутствующего инструмента: он остаётся ожидающим обработки до восстановления runtime.

После проверки вернуть исходный файл. Не проводить отрицательную проверку на рабочей установке мероприятия.
