# Проверка этапа 7 на Windows

## Цель

Проверить, что экран трансляции показывает операторскую стену из маленьких круглых превью, а панель оператора может добавить и убрать поздравление со стены.

## Автоматические проверки

Выполнить из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pytest
cd frontend
npm run build
cd ..
```

Автотесты покрывают:

- добавление на стену только ready+approved поздравлений;
- игнорирование устаревших `playback_id`;
- отсутствие дублей при повторном показе;
- отсутствие автоматического изменения стены после пропуска, ошибки или отмены;
- ограничение видимой стены выбранным шаблоном;
- скрытие и восстановление элемента стены через серверное состояние.

## Ручная проверка

1. Запустите сервер: `.\.venv\Scripts\python.exe run_server.py`.
2. Откройте `http://127.0.0.1:8000/admin`.
3. Откройте `http://127.0.0.1:8000/screen`.
4. Создайте или выберите мероприятие.
5. Откройте приём и отправьте несколько настоящих Telegram-видеокружочков.
6. Одобрите минимум два ролика и добавьте их на стену.
7. На `/screen` нажмите «Запустить показ».
8. В `/admin` нажмите «Запустить».
9. Дождитесь завершения первого ролика.
10. Убедитесь, что состав стены не изменился сам собой.
11. Дождитесь завершения второго ролика.
12. Убедитесь, что на стене остались два выбранных превью.
13. Нажмите «Показать повторно» для уже завершённого ролика и проиграйте его снова.
14. Убедитесь, что дубль этого ролика на стене не появился.
15. Запустите ролик и нажмите «Пропустить».
16. Убедитесь, что пропуск не изменил состав стены.
17. В `/admin` откройте блок «Стена».
18. Нажмите «Убрать со стены» у одного элемента.
19. Убедитесь, что он исчез со стены на `/screen`.

## Ожидаемый результат

- `/api/health` возвращает `stage: 7`.
- `/api/state` содержит массив `wall`.
- На `/screen` в ожидании и во время показа видны маленькие круглые превью стены.
- На стене отображается не больше элементов, чем разрешает выбранный шаблон.
- Повторный показ не создаёт второй экземпляр того же поздравления.
