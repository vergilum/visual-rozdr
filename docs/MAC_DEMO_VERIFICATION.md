## Проверено автоматически

Для каждой архитектуры успешно завершились:

- нативная сборка FFmpeg/x264 и проверка отсутствия сторонних dylib;
- desktop-проверки платформенных путей, fullscreen-переноса и состава ресурсов;
- Vite/TypeScript, PyInstaller и упаковка Electron;
- backend-тесты;
- packaged HTTP, `/admin`, `/screen`, JS/CSS и WebSocket snapshot;
- H.264/AAC-видео и JPEG-превью встроенными FFmpeg/ffprobe;
- штатная остановка backend;
- проверка ad-hoc подписи `codesign --verify --deep --strict`;
- запуск настоящего Electron `.app`: панель, экран, обе темы, изображения, QR, регистрация экрана;
- распаковка конечного ZIP и повторная GUI-проверка извлечённого приложения.

Локально на Windows прошли 73 backend-теста, 8 desktop-тестов, frontend build и GUI smoke
контрольной распакованной Windows-сборки с новым Electron-кодом.

Первый запуск CI обнаружил нативное падение Electron при открытии экрана. Исправлены обработчики
display events: нативный объект события больше не передаётся напрямую в renderer IPC.
Повторная сборка и GUI-проверки прошли для обеих архитектур.

## Что должен проверить получатель

Сборки проверены на macOS 15.7.9, а не на целевой Golden Gate 27.0.1.
Сценарий ручной проверки находится в `MAC_DEMO_USER_GUIDE.md`: первый запуск с Gatekeeper,
личный `.env`, настоящий Telegram-кружочек, столы, модерация, видео, звук, обе темы,
интерактивная стена, второй монитор/проектор и восстановление после перезапуска.

Это demo с ad-hoc подписью, без Developer ID и нотарификации Apple. Подтверждение первого
открытия может потребоваться. Двухчасовой прогон/50 роликов пока не зафиксированы.
Пользовательские токены, базы и медиа в Git и в архивы не включены.
