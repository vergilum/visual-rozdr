# Neutral theme assets

Папка для ассетов темы `neutral` (`Нейтральный`).

Файлы темы:

- `background.png` (`1698x926`) — основной фон экрана.
- `zone-overlay.png` (`1698x926`) — прозрачный слой с белой рабочей зоной в правых 35% изображения; белый цвет имеет прозрачность 45%.
- `circle-frame.png` — рамка для круглых превью.

Эти файлы подключаются frontend-темой `neutral` на `/screen`. В рабочей зоне размещаются максимум 12 кружочков, равномерной сеткой 3×4.
